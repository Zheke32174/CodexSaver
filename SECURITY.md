# Security Policy

## Reporting a Vulnerability

This repository contains CodexSaver, a cost-aware LLM delegation tool.
If you discover a security-relevant issue, contact the repository steward
through the MODOS governance channel. Do not open a public issue.

## Scope

- Unauthorized task delegation or privilege escalation
- Secrets exposure
- Code execution vulnerabilities
- Prompt injection affecting delegation decisions

This is a research project under the Pleiades Factory lightning-round process.
